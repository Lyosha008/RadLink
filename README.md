# RadLink Mod & Script Engine Documentation
=====================================
                        RADLINK SCRIPT ENGINE

Данный мод позволяет создавать кастомные предметы, события, блоки,
а также полностью кастомизировать Главное Меню игры с помощью
гибкой системы JSON-конфигураций и скриптов.

----------------------------------------------------------------------
1. СТРУКТУРА ПАПОК И РАЗМЕЩЕНИЕ ФАЙЛОВ
----------------------------------------------------------------------
Все конфигурационные JSON-файлы скриптов и меню хранятся в папке
игры и могут быть привязаны к конкретному миру или серверу.

А) ДЛЯ ОДИНОЧНЫХ МИРОВ:
run/saves/<Имя_Мира>/radlink/

Б) ДЛЯ СЕРВЕРОВ (Фон меню и кнопки под конкретный IP):
run/radlink/servers/<IP_Сервера_без_точек>/

Пример для play.example.com :
run/radlink/servers/play_example_com/menu_background.json

├── assets/              <-- папка кастомных ресурсов и текстур
├── data/                <-- данные генерации и датапаков
├── armor_item.json      <-- настройки и скрипты предметов брони
├── blocks.json          <-- скрипты поведения и событий блоков
├── effects.json         <-- регистрация и параметры эффектов
├── global.json          <-- глобальные события и тикеры мира
├── items.json           <-- скрипты предметов (включая right_click)
├── menu_background.json <-- кастомизация Главного Меню и кнопок
├── variables.json       <-- динамическое хранилище переменных
└── pack.mcmeta          <-- мета-данные датапака/ресурспака

----------------------------------------------------------------------
2. КОНФИГУРАЦИЯ МОДА (radlink-client.toml)
----------------------------------------------------------------------
В папке `run/config/radlink-client.toml` доступны основные параметры:

* isMenuChange = true / false
  - true:  Включает кастомный фон меню и перенастройку кнопок.
  - false: Полностью отключает все изменения меню (игра сохраняет
    100% ванильный вид, логотип, панораму и стандартные кнопки).

* serverOrWorldName = ""
  - Позволяет принудительно указать, из какого мира или сервера брать
    фон и настройки меню (menu_background.json).
  - Пример для мира: "MyAwesomeWorld"
  - Пример для сервера: "play.example.com"
  - Если оставлено пустым (""), мод автоматически загружает данные из
    последнего запущенного мира.

----------------------------------------------------------------------
3. НАСТРОЙКА ГЛАВНОГО МЕНЮ (menu_background.json)
----------------------------------------------------------------------
Позволяет изменять задний фон (включая GIF-подобную анимацию), менять
позиции и текстуры стандартных кнопок, скрывать их или добавлять новые.

СТРУКТУРА menu_background.json:

{
"fps": 20,                          // Скорость анимации фона (кадров в сек)
"frames": [                         // Кадры анимации фона (PNG файлы в папке)
"bg_0.png",
"bg_1.png",
"bg_2.png"
],
// Заместо "frames" можно указать статичный фон: "texture": "bg.png",

"buttons": {                        // Переопределение ванильных кнопок
"singleplayer": {
"x": 20, "y": 80,
"width": 180, "height": 30,
"texture": "btn_single.png",
"hover_texture": "btn_single_hover.png"
},
"multiplayer": {
"x": 20, "y": 120,
"width": 180, "height": 30
},
"language": {                     // Иконка языка (глобус)
"use": "No"                     // Полностью скрыть кнопку
},
"accessibility": {                // Иконка доступности (человечек)
"use": "No"                     // Полностью скрыть кнопку
},
"realms": {
"use": "No"                     // Скрыть кнопку Realms
}
},

"custom_buttons": [                 // Дополнительные кастомные кнопки
{
"text": "Гайд по моду",
"x": 20, "y": 200,
"width": 180, "height": 20,
"url": "https://wiki.example.com", // Открывает ссылку в браузере
"use": "Yes"
}
]
}

* Ключи стандартных кнопок в "buttons":
  - singleplayer   (Одиночная игра)
  - multiplayer    (Сетевая игра)
  - mods           (Моды)
  - options        (Настройки)
  - quit           (Выйти из игры)
  - language       (Выбор языка / Иконка глобуса)
  - accessibility  (Настройки доступности / Иконка человека)
  - realms         (Minecraft Realms)

* Параметр "use":
  - Принимает значение "No", "false" или "0" для полного скрытия кнопки.

4. КРИТИЧЕСКИ ВАЖНО: Разница между "if" и "If" в скриптах
----------------------------------------------------------------------
Регистр символов имеет ключевое значение при составлении JSON-скриптов!

* "if" (Главный блок условий):
  - Проверяется В НАЧАЛЕ обработки события.
  - Определяет, запустится ли скрипт вообще.
  - Содержит глобальный контекст ("who": "entity" / "block",
    проверку предмета в руке "item", временные циклы "timeCycles" и т.д.)[cite: 1].

* "If" / "iF" (Вложенное условие внутри "then"):
  - Проверяется ВНУТРИ списка действий (динамически)[cite: 1].
  - Используется для ветвления логики (аналог конструкции if-then-else).
  - Позволяет выполнить конкретное действие "Then" только при выполнении
    условия (например, проверке переменной через "query" или состояния блока)[cite: 1].

----------------------------------------------------------------------
5. ОСНОВНЫЕ УСЛОВИЯ ПРОВЕРКИ СКРИПТОВ ("if" / "If")
----------------------------------------------------------------------
* "entity": "player" | "zombie" — проверка типа сущности.
* "item": "minecraft:diamond" — проверка предмета в главной руке.
* "lit": true | false — проверка состояния блока (горит/зажжен).
* "query": { "global_atmosphere": { ">=": 10 } } — проверка значений переменных.
* "timeCycles": { "now": "isNewDay" } — проверка наступления нового дня.

----------------------------------------------------------------------
6. ДОСТУПНЫЕ ДЕЙСТВИЯ СКРИПТОВ ("then" / "Then")
----------------------------------------------------------------------

* explosion — Создание взрыва (на месте сущности или блока):
  { "explosion": { "radius": 4.0, "fire": false } }

* summon — Призыв сущности:
  { "summon": { "type": "minecraft:zombie", "count": 1 } }

* damage — Нанесение магического урона сущности:
  { "damage": 5.0 }

* effect — Наложение эффекта зелья:
  { "effect": { "id": "minecraft:regeneration", "duration": 100, "amplifier": 1 } }

* sound — Воспроизведение звука:
  { "sound": { "id": "minecraft:entity.experience_orb.pickup", "volume": 1.0, "pitch": 1.0 } }

* particle — Спавн частиц:
  { "particle": { "type": "minecraft:flame", "count": 10, "speed": 0.1 } }

* say / message — Сообщение в чат (поддерживает плейсхолдеры \${переменных}):
  { "say": { "text": "Текущая атмосфера: \${global_atmosphere}" } }

* add / set (переменные) — Изменение или установка числовых значений:
  { "add": { "global_atmosphere": 1.0 } }

  * set (блоки) — Установка одиночного блока или заполнение (fill) области:

    а) Одиночный блок (mode_type: "set_block"):
    {
    "set": [
    {
    "mode": [
    { "mode_type": "set_block" },
    { "coordinates_1": [{ "~": "0" }, { "~": "1" }, { "~": "0" } ] }
    ],
    "block": "minecraft:fire"
    }
    ]
    }

    б) Заполнение области (mode_type: "fill"):
    {
    "set": [
    {
    "mode": [
    { "mode_type": "fill" },
    { "coordinates_1": [{ "~": "-1" }, { "~": "-1" }, { "~": "-1" }] },
    { "coordinates_2": [{ "~": "1" }, { "~": "-1" }, { "~": "1" }] }
    ],
    "block": "minecraft:diamond_block",
    "tests": [
    { "isAir": false, "type": "destroy", "filter": "white_wool" }
    ]
    }
    ]
    }

----------------------------------------------------------------------
7. ПЕРЕМЕННЫЕ И ПЛЕЙСХОЛДЕРЫ
----------------------------------------------------------------------
- Переменные с префиксом "global_" (например, ${global_atmosphere})
  сохраняются для всего мира в variables.json.
- Обычные переменные автоматически привязываются к UUID игрока
  или координатам блока.

{

}

]
}
]
}
